# Comment Player for iPad — Roadmap

Плеер для iPad для покадрового просмотра видео, комментирования по тайм-коду,
рисования пометок на кадре и выгрузки таблицы ревью (тайм-код · комментарий · скриншот с пометками).

## Технологический стек

| Задача | Технология |
|---|---|
| UI | SwiftUI (iPadOS 17+) |
| Воспроизведение | AVFoundation: `AVPlayer`, `AVPlayerItemVideoOutput` |
| Покадровый шаг | `AVPlayerItem.step(byCount:)` + `seek` с нулевым допуском |
| Тайм-код из файла | Трек `tmcd` (`AVMediaType.timecode`) + `CMTimeCodeFormatDescription` |
| Захват кадра | `AVAssetImageGenerator` (tolerance = .zero) |
| Рисование | PencilKit (`PKCanvasView`, Apple Pencil) |
| Хранение | SwiftData (проекты, маркеры, рисунки) |
| Экспорт | XLSX с картинками, PDF, CSV + папка PNG |
| Сборка проекта | XcodeGen (`project.yml` вместо ручного `.xcodeproj`) |

Поддерживаемые форматы — то, что умеет AVFoundation: MOV, MP4, M4V (H.264, HEVC, ProRes на iPad с M-чипами).
MXF и прочие «вещательные» контейнеры нативно не открываются — вынесено в «Будущее».

## Этап 0 — Каркас проекта
- [ ] `project.yml` (XcodeGen), таргет iPad, iPadOS 17+
- [ ] Структура: `App/`, `Features/Player`, `Features/Review`, `Features/Export`, `Core/Timecode`
- [ ] Отдельный Swift-пакет `TimecodeKit` (чистая логика, покрыта unit-тестами)
- [ ] `.gitignore`, README с инструкцией сборки

**Результат:** пустое приложение запускается на iPad / симуляторе.

## Этап 1 — Плеер и покадровая навигация
- [ ] Импорт видео: Files (`fileImporter`), Photos (`PhotosPicker`), drag & drop
- [ ] Security-scoped bookmarks — файл открывается повторно после перезапуска
- [ ] Play / Pause, скраббер (таймлайн) с точным позиционированием
- [ ] Шаг ±1 кадр, ±10 кадров, ±1 секунда
- [ ] Удержание кнопки шага → «прокрутка» кадров
- [ ] Jog-жест: горизонтальный свайп по видео = покадровый скраб
- [ ] Горячие клавиши для Magic Keyboard: ←/→ кадр, J/K/L, пробел
- [ ] Скорость воспроизведения (0.25×–2×)

**Критерий готовности:** каждое нажатие «+1 кадр» сдвигает ровно на один кадр, без пропусков и повторов.

## Этап 2 — Движок тайм-кода (ключевой этап)
- [ ] Чтение стартового тайм-кода из трека `tmcd` (через `AVAssetReader`)
- [ ] Определение FPS: `nominalFrameRate`, `minFrameDuration`, `frameQuanta` из описания тайм-кода
- [ ] Поддержка 23.976, 24, 25, 29.97 DF/NDF, 30, 50, 59.94, 60
- [ ] Drop-frame (`;` в отображении) — корректная формула пересчёта
- [ ] Конвертация `CMTime ⇄ номер кадра ⇄ HH:MM:SS:FF`
- [ ] Если `tmcd` нет — старт 00:00:00:00, с возможностью задать вручную
- [ ] Поле ввода тайм-кода → переход точно на этот кадр
- [ ] Unit-тесты: граничные значения DF (00:00:59;29 → 00:01:00;02), переход через 24 ч
- [ ] Предупреждение для VFR-видео (переменная частота — например, запись с iPhone)

**Критерий готовности:** тайм-код в плеере совпадает с тайм-кодом этого же кадра в DaVinci Resolve / Premiere.

## Этап 3 — Маркеры и комментарии
- [ ] Пауза → кнопка «Комментарий» → маркер на текущем кадре
- [ ] Текстовый комментарий (+ диктовка через клавиатуру iOS)
- [ ] Боковая панель списка маркеров, тап → переход к кадру
- [ ] Отметки маркеров на таймлайне
- [ ] Редактирование / удаление, статус (открыт / исправлено)
- [ ] Сохранение в SwiftData: Проект → Видео → Маркеры

## Этап 4 — Пометки на кадре
- [ ] Режим рисования: стоп-кадр + `PKCanvasView` поверх
- [ ] Инструменты: перо, маркер, ластик, цвета, толщина
- [ ] Стрелки, прямоугольники, круги, текстовые подписи (свой слой поверх PencilKit)
- [ ] Отмена / повтор
- [ ] Рисунок хранится в координатах кадра (не экрана) — не «съезжает» при повороте iPad
- [ ] Рендер: исходный кадр в полном разрешении + пометки → PNG/JPEG

## Этап 5 — Экспорт таблицы
- [ ] Предпросмотр таблицы в приложении
- [ ] **XLSX**: колонки `№ | Тайм-код | Комментарий | Скриншот` — картинка встроена в ячейку
- [ ] **PDF**: та же таблица, удобно отправить заказчику
- [ ] **CSV + папка PNG** (ZIP)
- [ ] Шапка: имя файла, FPS, стартовый TC, дата, автор
- [ ] Share Sheet: почта, Telegram, Files, AirDrop
- [ ] Настройки: размер скриншота, только кадры с комментариями / все

## Этап 6 — Полировка и выпуск
- [ ] Несколько проектов / версий видео
- [ ] Производительность на 4K / ProRes
- [ ] Тёмная тема, Stage Manager, Split View
- [ ] Иконка, онбординг
- [ ] TestFlight → App Store

## Будущее (после v1.0)
- Экспорт маркеров для монтажных программ: EDL, CSV для DaVinci Resolve, FCPXML для Final Cut, маркеры Premiere
- Синхронизация через iCloud (SwiftData + CloudKit)
- Сравнение двух версий видео (A/B, наложение)
- Поддержка MXF и других форматов (через FFmpeg)
- Совместное ревью несколькими пользователями

## Как работаем
- Код пишется здесь, в репозитории. **Сборка и запуск — только на Mac с Xcode 16+** (в облачной среде нет Xcode).
- Логику тайм-кода держим в отдельном пакете, чтобы её можно было тестировать без iPad.
- Каждый этап — отдельная ветка и PR, после сборки на устройстве — обратная связь и следующий этап.
