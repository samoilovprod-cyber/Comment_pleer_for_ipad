# Comment Player for iPad — Roadmap

Плеер для iPad для покадрового просмотра видео, комментирования по тайм-коду,
рисования пометок на кадре и выгрузки таблицы ревью (тайм-код · комментарий · скриншот с пометками).

## Технологический стек

| Задача | Технология |
|---|---|
| UI | SwiftUI (iPadOS 17+, работает на iPadOS 26) |
| Воспроизведение | AVFoundation: `AVPlayer`, `AVPlayerItemVideoOutput` |
| Покадровый шаг | `AVPlayerItem.step(byCount:)` + `seek` с нулевым допуском |
| Тайм-код из файла | Трек `tmcd` (`AVMediaType.timecode`) + `CMTimeCodeFormatDescription` |
| Захват кадра | `AVAssetImageGenerator` (tolerance = .zero) |
| Рисование | PencilKit (`PKCanvasView`, Apple Pencil) |
| Хранение | SwiftData (проекты, маркеры, рисунки) |
| Экспорт | Выбор при выгрузке: XLSX с картинками или PDF |
| Сборка проекта | XcodeGen (`project.yml` вместо ручного `.xcodeproj`) |

Основные форматы: **ProRes и H.264, 24 и 25 fps** — на них тестируем в первую очередь.
Остальное, что умеет AVFoundation (MOV, MP4, M4V, HEVC, 23.976, 29.97 DF и т.д.), тоже поддерживается.
MXF и прочие «вещательные» контейнеры нативно не открываются — вынесено в «Будущее».

- [x] Импорт видео: Files (`fileImporter`), Photos (`PhotosPicker`), drag & drop
- [x] Security-scoped bookmarks — файл открывается повторно после перезапуска

✅ Проверено на iPad.

## Этап 2 — Движок тайм-кода (ключевой этап)
- [x] Чтение стартового тайм-кода из трека `tmcd` (через `AVAssetReader`)
- [x] Определение FPS: `nominalFrameRate`, `minFrameDuration`, `frameQuanta` из описания тайм-кода
- [x] Поддержка 23.976, 24, 25, 29.97 DF/NDF, 30, 50, 59.94, 60
- [x] Drop-frame (`;` в отображении) — корректная формула пересчёта
- [x] Конвертация `CMTime ⇄ номер кадра ⇄ HH:MM:SS:FF`
- [x] Если `tmcd` нет — старт 00:00:00:00, с возможностью задать вручную
- [x] Поле ввода тайм-кода → переход точно на этот кадр
- [x] Unit-тесты: граничные значения DF (00:00:59;29 → 00:01:00;02), переход через 24 ч
- [x] Предупреждение для VFR-видео (переменная частота — например, запись с iPhone)

**Критерий готовности:** тайм-код в плеере совпадает с тайм-кодом этого же кадра в DaVinci Resolve / Premiere.
✅ Проверено на устройстве: тайм-код совпадает с DaVinci Resolve.

## Этап 7 — Маркеры для DaVinci Resolve и Premiere Pro (бонус)
Маркер в монтажке — это только тайм-код, цвет, имя и текст; картинку в него не вложить.
Поэтому пометки передаём так:

- [ ] **Пакет экспорта (папка/ZIP):**
  - `markers.xml` — таймлайн в формате FCP 7 XML (импортируют и Resolve, и Premiere):
    - V1 — исходный клип, маркеры с комментариями на нужных кадрах
    - V2 — **прозрачные PNG с пометками** на тех же тайм-кодах (длиной в 1–2 сек) —
      монтажёр видит рисунок прямо поверх видео в своей программе
  - `annotations/` — PNG с альфа-каналом (только рисунок) и JPG (кадр + рисунок)
  - `markers_resolve.edl` — маркеры для Resolve (Timeline → Import → Timeline Markers from EDL)
  - `review.pdf` — таблица для людей
- [ ] В тексте маркера — имя файла скриншота, чтобы найти картинку
- [ ] Цвет маркера = статус / автор комментария
- [ ] Проверка импорта в Resolve 19+ и Premiere Pro 2025+

## Как работаем
- Код пишется в репозитории. **Сборка и запуск — на Mac с Xcode 16+**.
  Удобнее всего вести разработку в Claude Code прямо на Mac: там он сам собирает проект (`xcodebuild`) и исправляет ошибки компиляции.
- Логику тайм-кода держим в отдельном пакете, чтобы её можно было тестировать без iPad.
- Каждый этап — отдельная ветка и PR, после сборки на устройстве — обратная связь и следующий этап.
